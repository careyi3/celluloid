# Animation Files

This directory contains JSON animation files generated by various algorithm generators.

## Format

Each JSON file follows this structure:

```json
{
  "name": "Algorithm Name",
  "algorithm": "algorithm_type",
  "created_at": "2025-12-03T19:30:00Z",
  "grid_config": {
    "width": 50,
    "height": 50
  },
  "metadata": {
    "total_frames": 1332,
    "has_path": true,
    "frame_delay_ms": 50.0
  },
  "frames": [
    {
      "step": 0,
      "grid": [[0, 0, 1, ...], ...],
      "message": "Frame description",
      "highlighted": [[x, y], ...]
    }
  ]
}
```

**Note:** Files are generated in compact format (no whitespace) to minimize file size.

## Cell States

- `0` = Empty
- `1` = Obstacle
- `2` = Start
- `3` = End
- `4` = Visited
- `5` = Path

## Generating Animations

```bash
# From the workspace root
cd generators/dijkstra
cargo run --release -- 50 50 0.2 "my_animation"
```

Arguments:
1. Width (default: 50)
2. Height (default: 50)
3. Obstacle percentage (default: 0.2)
4. Output name (default: "dijkstra_WxH")
